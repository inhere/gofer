# 信箱按对话显示、会话以人物呈现 设计

## 背景与现状

用户 2026-10-20 实测两个会话互发信件后反馈：显示简陋，看不清信件之间的前后关系；markdown 没渲染；会话 id 认不出是谁，会话一多更分不清。

现状（`web/src/views/Mail.vue`，2026-10-20 截图核对）：

- 左栏按 `thread_id` 分组。一封**新信**（不是回信）就开一个新 thread，所以同一对会话来回几轮会变成多条，如截图里 `sess_261020_1iu81hh7i8v0014` 与 `e1a75a01-…` 之间出现五六条。
- 每条只显示对方的原始地址（`session:<完整 id>`），没有名字、项目、agent、在线状态。
- 右栏正文是纯文本，代码块、标题、列表都没渲染。

## 方案

### 一、对话 = 参与方对

- **对话**：同一对参与方（发信方 ↔ 收信方，不分方向）之间的全部信件。参与方用规范化身份表示：`session:<sid>`、`job:<id>`、`caller:<id>`（收集箱）。
- 左栏一行一个对话：显示两位人物（我方 / 对方；从「全部」视角看时两边都显示）、最后一封的摘要、未读数、急件标记、最后活动时间、信件数。
- 右栏是该对话的时间线：所有信件按时间从早到晚，气泡左右分（发信方在左、收信方在右，或「我方」在右）；同一个 thread 里的回信用细线串起来，并标注「回复 #N」，点击跳到被回复的那封。新信与回信的区别一眼可见。
- 投递状态（待投、已送达、已读、已答、待指派、失败）放在每个气泡的角上，保持现有的颜色。
- 原有的「收件 / 发件 / 待指派」筛选照常，作用在对话里的信件上。

### 二、会话以人物呈现

- **人物卡**（列表与时间线都用同一个组件）：
  - 名字：会话的主题（`session topic`），没有主题就用标题，再没有就用 agent + 项目；
  - 副行：agent（claude / codex / suga …）、项目、执行机、在线状态点（在线 / 空闲 / 等回复 / 离线 / 已结束）；
  - 颜色：按会话 id 稳定地取一个颜色（色板固定，深浅主题都可读），首字作头像；
  - 悬停显示完整 id、cwd、最后活动时间；点击打开会话抽屉。
- job 与收集箱也有人物卡：job 显示 job 标题与 agent；收集箱显示「你的收集箱（调用方名）」。

### 三、markdown 渲染

- 正文用会话抽屉同一个渲染器与安全策略（已有的 markdown 组件，HTML 消毒、代码块高亮、长文折叠）。
- 列表里的摘要仍是纯文本（去掉 markdown 标记）。

### 四、读接口补字段

- `GET /v1/mail` 每封信的 `from` / `to` 补一个 `persona` 对象（additive）：`{name, agent, project_key, runner, state, last_seen_at}`，由服务端按当前会话 / job 状态填写；读不到（已删除）时省略，前端退回显示 id。
- 新增 `GET /v1/mail/conversations?box=&limit=&offset=`：服务端按参与方对聚合，返回 `{peer_a, peer_b, last_mail, unread, urgent, count, activity_at}`，避免前端为了分组拉全量信件。`GET /v1/mail?peer=<地址>&with=<地址>` 取某个对话的信件。权限沿用 `GET /v1/mail` 的过滤规则（只聚合调用方看得到的信）。

## 范围与非目标

- 范围：上面四节；手机宽度下左栏与右栏切换显示（沿用现有的窄屏布局）。
- 非目标：广播；会话改名（显示名来自主题与标题）；信件搜索。

## 测试计划

- 分组纯函数：参与方对规范化（方向无关、收集箱与 job）、多个 thread 合并、未读与急件汇总。
- 人物名回退顺序；颜色稳定性。
- markdown 渲染与消毒（脚本标签被去掉）。
- 接口：conversations 聚合与权限过滤（看不到的信不计入）；persona 字段。
- 接线 `?raw` 断言与手机宽度截图。

## 决策

以下为本稿的提案，待用户确认：

1. **对话按参与方对聚合（推荐）**，thread 只作为对话里的回复关系展示。备选：仍按 thread，只是把同一对的 thread 折叠在一起。
2. **人物名用会话主题 → 标题 → agent + 项目**，不新增「会话改名」功能。
3. **聚合放服务端**（新增 conversations 接口），前端不再拉全量分组。
4. **气泡方向**：「我方」（当前查看者自己的会话 / 收集箱）在右，对方在左；两边都不是我方时，按对话里先发信的一方在左。
