## 背景与目标

v0.85–v0.88 先后上线了 ACP 持续会话、远程持续会话、web 给终端会话发消息。用户实际使用后反馈：工作台列了大量 job，多数不需要看或继续；创建 pty / ACP 会话要走完整的 job 创建表，参数太多；ACP job 详情的输入框又小又藏在信息区；「继续会话」对交互会话还要求填续接指令。目标：让 web 以"会话"为中心——工作台只放会话，Sessions 页能直接新建和查看三类会话，继续会话一键进入等待输入。

## 已确认事实（2026-10-01 核对代码）

- `web/src/views/JobDetail.vue`：「继续会话」表单的输入框占位为"续接指令（必填）"；对 interactive job 按钮在空输入时也可用（`:disabled="resuming || (!job.interactive && !resumePrompt.trim())"`），只是文案误导。ACP job 的继续走 `ResumeJob`：新开单轮 job，`session/load` 后执行续接指令，指令必填。
- 持续会话 job 的"下一条消息"输入在 job 信息区（meta 网格）里，是单行小输入框。
- 工作台的线程来源包含 agent job（每轮一个 job 的续聊）。
- 手机宽度下 `WorkbenchComposer.vue` 的 `.mobile-launch`（右下角固定 46px 圆形「＋」，`right:12px; bottom:12px; z-index:80`）在打开会话时压住了底部输入框的发送按钮。
- `gofer job run --interactive --prompt` 静默丢弃提示词（tools-ycj）。
- hook 不判断是否运行在 gofer job 内（tools-05l）。
- jcode 无内置交互会话规则（tools-5g9）。

## 方案

### S1 ACP job 详情的输入区

持续会话 job 的消息输入移出 job 信息区，放在「渲染命令」板块之后，改为与工作台一致的聊天输入框（复用工作台输入组件：多行、Ctrl/Cmd+Enter 发送、发送按钮、发送中状态）。「释放锁并结束」保留在页头。非等待输入状态时输入框禁用并说明原因（运行中 / 结束中 / 已结束）。

### S2 继续会话一键进入等待输入

- 「快速重建」不变：同参数全新 job，不带上下文。
- 「继续会话」统一为"接上原会话、续接指令选填"：
  - pty 交互 job：沿用现有 resume（重新打开终端回到原会话），占位改为"第一句话（可选）"。
  - ACP job（单轮或持续会话）：新开**持续会话** job，`session/load` 原会话后停在 `awaiting_input`；填了第一句话则作为第 1 轮发送。原来"带一条指令跑一轮就结束"的继续方式取消（用户确认）。
  - 原会话没有 session_id 时按钮禁用并说明原因。
- 同时修 tools-ycj：`job run --interactive --prompt` 把提示词作为初始输入（界面就绪后输入并提交，复用分段写入），HTTP / MCP 同口径。

### S3 工作台只放会话

工作台线程只来自三类会话：agent 终端会话（hook 注册的，如监督者会话）、pty 交互会话、ACP 持续会话。普通 job（批处理、单轮 ACP、exec 等）不再出现在工作台（用户确认），去 Board / job 详情查看；工作台"每轮一个 job"的续聊路径移除。已有的工作台布局 / 标签页 / 置顶数据中指向 job 线程的条目在加载时丢弃，不报错。

### S4 Sessions 页「新建会话」简洁表单

字段：会话类型（终端 pty / ACP 持续会话）、项目、agent（按类型与项目准入筛选可用项）、标题（可选）、第一句话（可选）。runner 默认本机，可选在线且支持该类型的 worker（ACP 会话需协议 ≥ v13）。表单顶部「完整配置」链接跳到 job 创建页并带上已选项。创建成功后直接打开该会话（pty 进终端，ACP 进对话抽屉）。

### S5 Sessions 页「ACP 会话」列表

与 agent 会话、终端会话并列：状态（运行中 / 等待输入 / 结束中 / 已结束）、轮次、agent、项目、runner、最后一条回复预览、空闲截止时间。点开为与 agent 会话一致的抽屉：对话（只含用户消息与 agent 回复）、输入框、「查看过程」链接、结束按钮。默认只列未结束的，可勾选显示已结束。

### S6 工作台按钮遮挡

打开会话时不显示右下角浮动「＋」，改在会话顶栏放「＋」；未打开会话时保留浮动按钮，并与底部安全区留出间距。

### S8 agent 会话"完整最新消息"入口可发现

用户反馈（2026-10-01）：Sessions 页 agent 会话列表只能看到最新消息的前几个字，找不到 v0.86 加的完整查看入口——现有入口是"点击整行打开抽屉"，列表上没有任何提示。改：消息预览旁加明显的「查看全文」按钮（点击打开抽屉并定位到最新消息）；抽屉顶部固定显示"最新消息"卡片（完整、可复制、实时更新），其下才是轮次时间线；有关联 job 时的跳转链接保留。手机宽度同样可用。

### S7 并入的三项

- tools-05l：hook 检测到 `GOFER_JOB_ID` 即放行，不注册会话、不等待 web 回复；补测试。
- tools-5g9：主机实测 jcode 的优雅退出命令、退出横幅、会话存储，补内置规则（exit_keys / session_capture / session_store_glob / resume），并评估在 job 环境中关闭其自动更新。
- tools-ycj：见 S2。

## 不做

- 不改变 job 本身的数据模型；会话列表基于现有 job / agent 会话 / pty 会话数据。
- 不做工作台以外页面的大改版。

## 测试与验收

- 每项先写失败测试（Go / Vitest），按功能点提交。
- 真实复验（监督者在容器内）：Sessions 页用简洁表单分别新建 pty 与 ACP 会话；ACP 会话在抽屉里对话两轮；对已结束的 ACP job 点「继续会话」不填指令进入等待输入并引用上下文；工作台只出现三类会话；手机宽度截图确认发送按钮可点；`job run --interactive --prompt` 的提示词被提交。
