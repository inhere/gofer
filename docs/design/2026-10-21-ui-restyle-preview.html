这一版改了什么

设计说明保持中文 · notes stay in Chinese

  1. 壳层：一行塞 14 个目标 → 左轨 + 工具行

    顶栏原来挤着 6 个导航链接、6 个状态/动作按钮。改成左侧分组轨道（工作 / 配置），顶栏只留搜索（⌘K）、信箱、通知、新建任务。宽度够用，导航也能继续加。

  2. 手机：抽屉 + 可拖半圆 → 底部标签栏

    窄屏入口挪到拇指区，5 个标签（今天 / 工作台 / 工作项 / 任务 / 更多），保留 safe-area-inset。贴边 rail-toggle 及其拖动逻辑可以整块删掉。

  3. 字号：10–12px 微字 → 12/13/14/16/20/26

    正文 14、最小 12，行高放宽到 1.5–1.6；mono 只留给 ID、数字、日志、状态键，标题和正文回到 sans。现网 90 个组件里有 10–11px 声明。

  4. 表面：发丝线 + 4px 直角 → 12px 圆角 + 内高光 + 单一浮层阴影

    卡片、面板、表格头共用一套卡面：1px 发丝线 + 顶部 1px 内高光；深色下靠「表面提亮」分层，阴影只给浮层（侧板 / toast / 菜单）——铺满地给每张卡加同一种软阴影就是 AI 素材样板。低圆角仍是产品性格，只是从 4 提到 12。

  5. 状态：满饱和文字 → tint 胶囊 + 呼吸点

    12% 底 / 34% 边 / 实心点，运行中 2s 呼吸；颜色语义不动（琥珀等待、哑绿完成、砖红失败、石板排队，accent 只做交互强调）。

  6. 间距与版式节奏

    间距 4/8/12/16/24/32/40；桌面内容宽度上限 1140；页面顶部只在有真信息时给一行上下文（日期 / 范围），不再每个标题上方挂一个小标签；手机 16px 边距、数字块两列。

  7. 共享基元替代逐页复制

    按钮 / 徽标 / 输入 / 卡面 / 表格 / 空状态收进一份全局 base.css，SFC 只写页面自己的布局；现在 .empty 在 20 个文件里各写一份、.card 9 份、断点 15 种。

  8. 落地顺序与风险

    先 tokens.css 加尺度 token、再落基元、再逐屏替换；~175 个 vitest 用例靠 SFC 源码文本断言，class / 结构改名要同步改断言，一步一屏提交更稳。

  9. 双语：zh / en 可切换

    顶栏右侧常驻语言切换（选项用目标语言写法，不用国旗）。本页已接上：切换后文案、title / placeholder / aria-label 与 <html lang> 一起变。标识符、命令、路径、job id 不译（GitLab 翻译指南的做法）。

  10. 长度不能靠截断兜

    中文是最短的一侧，同类标签英文普遍宽 1.4–2×（「进度」→ Progress 已经 2×）。规则：导航 / 按钮 / tab 允许两行、不截断；表格单元格截断 + tooltip；芯片按 1.6× 中文宽定最小宽；日期数字走 Intl，不用手拼。

  11. 参考来源

    W3C i18n（文本膨胀与重排）、Carbon / Atlassian（分层与数据密集字阶）、Android（底部 tab 3–5 个）、GitLab（技术术语不译）、anthropics/skills 的 frontend-design（反模板清单：全大写小标签、中点串、同一种卡片阴影与圆角）。
